## PART 1：回測四策略

### 為什麼要回測？

- 人類直覺對投資報酬的判斷通常**嚴重偏差**
- 回測用 20 年真實股價，消除「我覺得」的偏見
- 讓數據告訴你：擇時 vs 不擇時，差距到底多大？

---

### Slide 2 — 策略一：單筆投入（Lumpsum）

**邏輯**：第一天就把所有資金 All-in

```
總投入 = 每月預算 × 總月數
第一個交易日 → 全額買入
```

**適用情境**：
- 繼承遺產、領到一大筆獎金
- 相信「時間在市場裡 > 擇時進場」

**財經知識 — Time in the Market**：
- Vanguard 研究指出，約 **2/3 的情況下**，單筆投入優於 DCA
- 原因：市場長期向上，越早投入 = 越多時間享受複利
- 風險：如果在高點 All-in，短期可能承受 30-50% 的帳面虧損

> 關鍵指標：這個策略的 XIRR 通常最高，但**心理壓力也最大**。

---

### Slide 3 — 策略二：定期定額 DCA

**邏輯**：每月固定金額買入，不管股價高低

```
每月第一個交易日 → 買入固定金額
股價高 → 買到較少股數
股價低 → 買到較多股數
```

**適用情境**：
- 每月有固定薪資收入的上班族
- 不想花時間盯盤、判斷高低點

**財經知識 — Dollar Cost Averaging**：
- 自動實現「低買多、高買少」的紀律
- 長期下來，平均成本會趨近於**調和平均數**（比算術平均低）
- 最大優勢不是報酬率，而是**行為面**：避免恐慌賣出、貪婪追高

**數學原理**：

```
假設兩個月分別股價 $100 和 $50，每月投入 $10,000

DCA：
  第 1 月買 100 股（$10,000 / $100）
  第 2 月買 200 股（$10,000 / $50）
  合計 300 股，成本 $20,000
  平均成本 = $20,000 / 300 = $66.7（低於算術平均 $75）
```

> DCA 的報酬率通常不是最高，但它是**普通人最容易堅持的策略**。

---

### Slide 4 — 策略三：天選之人（Lucky）

**邏輯**：每年剛好買在最低點

```
每年的年度最低價那天 → 投入全年預算（月投 × 12）
```

**這是上限參考值**：
- 現實中**沒有人能每年精準抓到最低點**
- 用來回答：「如果我有完美擇時能力，能多賺多少？」
- 與 DCA 的差距 = **擇時的理論最大價值**

**財經知識 — 擇時的代價**：
- Charles Schwab 研究（1926-2021）：錯過市場最好的 10 天，報酬率下降超過一半
- 試圖擇時的人，往往在最低點恐慌賣出，在最高點貪婪追入
- 天選之人的存在告訴我們：**即使擇時完美，和 DCA 的差距可能沒你想的大**

---

### Slide 5 — 策略四：地獄倒霉鬼（Unlucky）

**邏輯**：每年剛好買在最高點

```
每年的年度最高價那天 → 投入全年預算
```

**這是下限參考值**：
- 如果你每年都買在最高點，20 年後結果如何？
- 答案通常讓人意外：**即使是最差擇時，長期仍然賺錢**

**財經知識 — 最重要的發現**：

```
以 0050.TW 為例（2005-2024 回測）：

天選之人  IRR ≈ 10-12%
DCA       IRR ≈ 8-10%
倒霉鬼    IRR ≈ 6-8%

差距 ≈ 2-4%，但三者都是正報酬！
```

> 結論：**買什麼**比**什麼時候買**重要得多。長期持有優質標的，即使擇時最差也能獲利。

---

### Slide 6 — XIRR：真正的年化報酬率

**為什麼不用簡單報酬率？**

```
簡單報酬率 = (終值 - 成本) / 成本
問題：沒考慮每筆投入的時間差異
```

**XIRR（Extended Internal Rate of Return）**：
- 考慮每筆現金流的**精確日期**
- 第一個月投入的 1 萬元，複利了 20 年
- 最後一個月投入的 1 萬元，只複利了 1 個月
- XIRR 把這些都考慮進去，給出**等效年化報酬率**

**計算方法 — Newton-Raphson 迭代**：

```
NPV(r) = Σ CFᵢ / (1+r)^(tᵢ/365.25) = 0

找到讓 NPV = 0 的 r，就是 XIRR
```

## PART 2：樂活五線譜

### Slide 7 — 什麼是樂活五線譜？

一種基於**均值回歸**的技術分析工具。

**核心假設**：股價長期會沿著趨勢線波動，偏離太多終會回歸。

```
股價走勢（對數尺度）：

  🔴 +2σ ─────────────────── 極度樂觀（歷史偏貴）
  🟠 +1σ ─ ─ ─ ─ ─ ─ ─ ─ ─ 相對樂觀
  ⚪ 趨勢 ═══════════════════ 長期均值
  🔵 -1σ ─ ─ ─ ─ ─ ─ ─ ─ ─ 相對悲觀
  🟣 -2σ ─────────────────── 極度悲觀（歷史偏便宜）
```

---

### Slide 8 — 計算原理

**Step 1：取對數**
```
為什麼要取 ln？
因為股價成長是「複利」的，用對數轉換後才是線性趨勢
$100 → $200（漲 100%）和 $200 → $400（漲 100%）
在對數尺度上是等距的
```

**Step 2：線性迴歸（OLS）**
```
ln(Price) = slope × t + intercept

slope = 長期年化成長率（對數）
intercept = 起始值
```

**Step 3：計算標準差 σ**
```
殘差 = 實際 ln(Price) - 預測 ln(Price)
σ = sqrt(Σ殘差² / (n-2))
```

**Step 4：畫出五條線**
```
各線 = exp(趨勢值 ± k × σ)，k = 0, ±1, ±2
```

---

### Slide 9 — 如何使用五線譜？

**買賣參考**：

| 區間 | 位置 | 建議動作 | 心理狀態 |
|------|------|----------|----------|
| 極度樂觀 | > +2σ | 考慮減碼 | 市場狂熱，新聞都在報「XX 創新高」 |
| 相對樂觀 | +1σ ~ +2σ | 觀望或小賣 | 感覺不錯，但要注意 |
| 合理區間 | -1σ ~ +1σ | 持續持有/定期定額 | 正常波動 |
| 相對悲觀 | -2σ ~ -1σ | 加碼買入 | 市場恐慌，新聞唱衰 |
| 極度悲觀 | < -2σ | 積極買入 | 「完蛋了」的感覺，通常是最好的進場點 |

**兩個重要指標**：

- **R²（決定係數）**：> 0.85 表示趨勢擬合良好，五線譜可信度高
- **CV（變異係數）**：越小表示股價越穩定，五線譜越準確

> 適合標的：大盤 ETF（0050.TW、VOO）、穩定成長股。不適合：高波動個股、景氣循環股。

---

### Slide 10 — 五線譜的統計學基礎

**常態分佈假設**：

```
如果殘差呈常態分佈：
  ±1σ 範圍 → 包含 68.2% 的歷史資料
  ±2σ 範圍 → 包含 95.4% 的歷史資料

股價落在 -2σ 以下的機率 ≈ 2.3%（非常少見）
```

**均值回歸（Mean Reversion）**：
- 短期股價受情緒驅動，可能大幅偏離趨勢
- 長期來看，價格傾向回到趨勢線附近
- 巴菲特：「別人恐懼時我貪婪，別人貪婪時我恐懼」— 就是均值回歸的應用

---

### Slide 12 — 殖利率：投資人最愛的指標

**殖利率（Dividend Yield）**：

```
殖利率 = 年配息金額 / 股價 × 100%

範例：00919 股價 22.50，年配 2.34
殖利率 = 2.34 / 22.50 = 10.4%
```

**殖利率的意義**：
- 代表「每投入 1 元，一年能拿回多少現金」
- 高殖利率 ≠ 好投資（可能是股價暴跌造成的）
- 要看**填息率**：配息後股價能不能漲回來？

**填息**：
```
除息前：股價 $25，配息 $0.55
除息後：股價 $24.45（自動扣掉配息）
填息 = 股價漲回 $25 → 你才真正「賺到」這 $0.55
```

> 如果不填息，配息只是「左口袋換右口袋」。

### Slide 13 — 四種配置策略

#### 策略 A：均等分配

```
本金 600 萬 → 每支 ETF 各 200 萬

0056:  200萬 / 37.82元 / 1000股 = 52 張
00878: 200萬 / 22.03元 / 1000股 = 90 張
00919: 200萬 / 22.50元 / 1000股 = 88 張
```

- 最簡單、最直覺
- 沒有考慮殖利率差異

---

#### 策略 B：最大配息（貪心法）

**邏輯**：殖利率最高的買最多，總配息最大化

```
Step 1: 先各買 1 張（確保月月都有配息）
Step 2: 剩餘資金 → 全買殖利率最高的 ETF

殖利率排序：00919 (10.4%) > 00878 (6.4%) > 0056 (5.7%)
結果：00919 買到 264 張，其他各 1 張
```

- 總月配息最高（可能多出 30-40%）
- 代價：配息集中在 3/6/9/12 月，其他月份幾乎沒收入
- 風險集中：過度依賴單一 ETF

---

#### 策略 C：殖利率加權

**邏輯**：依殖利率比例分配，高殖利率 ETF 多買，但不極端

```
殖利率比例：
0056:  5.74 / 22.59 = 25.4%
00878: 6.45 / 22.59 = 28.6%
00919: 10.40 / 22.59 = 46.0%

600 萬分配：
0056:  152 萬 → 40 張
00878: 171 萬 → 78 張
00919: 276 萬 → 123 張
```

- 兼顧配息最大化與分散性
- 比均等分配多 ~8% 月配息
- 每月都有配息，但金額不均等

---

#### 策略 D：月月均配

**邏輯**：讓每支 ETF 產生的年配息相等，月月現金流最穩定

```
數學推導：
  目標：shares_i × 1000 × dividend_i = D（相同）

  D = Capital / Σ(price_i / dividend_i)

600 萬：
  D = 6,000,000 / (37.82/2.17 + 22.03/1.42 + 22.50/2.34)
  D = 6,000,000 / 42.56 = 140,979

0056:  64 張（年配 138,880）
00878: 100 張（年配 142,000）
00919: 61 張（年配 142,740）
```

- 每支 ETF 年配息幾乎相同 → 每季收到的金額接近
- 月月現金流最穩定，適合真正靠配息過生活的退休族
- 總配息略低於最大配息策略

## PART 4：重要財經觀念

### Slide 15 — 複利：第八大奇蹟

```
愛因斯坦（據傳）：「複利是世界第八大奇蹟。」

每月投入 $10,000，年化報酬 8%：
  10 年後 →   183 萬（投入 120 萬）
  20 年後 →   589 萬（投入 240 萬）
  30 年後 → 1,490 萬（投入 360 萬）

後 10 年增加的金額 > 前 20 年的總和！
```

> 複利的力量來自**時間**，越早開始越好。

### Slide 16 — 風險與報酬的取捨

```
高報酬 = 高風險（沒有例外）

          報酬
           ↑
           │         🔴 個股
           │      🟠 主動型基金
           │   🟡 ETF（0050, VOO）
           │  🟢 高股息 ETF
           │ 🔵 債券
           │💜 定存
           └───────────────→ 風險
```

**本工具涉及的標的都屬於「高股息 ETF」區間**：
- 風險低於個股（分散持有數十檔成分股）
- 報酬可能低於成長型 ETF（如 0050）
- 適合追求穩定現金流的投資人

### Slide 17 — 投資常見迷思

| 迷思 | 真相 |
|------|------|
| 「等跌了再買」 | 研究顯示不擇時的 DCA 長期表現不差，等待的機會成本更大 |
| 「高殖利率 = 高報酬」 | 配息來自股價，不填息等於沒賺。要看「總報酬 = 資本利得 + 配息」 |
| 「分散投資就安全」 | 分散降低個股風險，但無法消除系統性風險（如金融海嘯、全球衰退） |
| 「過去績效代表未來」 | 回測告訴你歷史，但未來可能不同。回測是參考，不是保證 |
| 「定期定額穩賺不賠」 | 長期向上的標的才適合 DCA，如果標的持續下跌，DCA 只是攤平虧損 |

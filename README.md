# StockPilot 投資分析工具

> 投資策略回測 ｜ 樂活五線譜 ｜ 歷史價格查詢 — 真實數據驅動的投資分析工具

用 Yahoo Finance 真實歷史股價，幫你回答三個問題：
1. **策略回測**：不擇時 DCA vs 天選之人 vs All-in，20 年下來差多少？
2. **五線譜**：現在股價貴了還是便宜了？歷史趨勢怎麼說？
3. **價格查詢**：任意區間的 OHLCV + 調整後股價一目了然

---

## 功能總覽

### 📊 回測分析（四策略比較）

| 策略 | 說明 | 現實性 |
|------|------|--------|
| 💰 **單筆投入** | 第一天 All-in 全部資金 | ❌ 需提前擁有全部資金 |
| 🍀 **天選之人** | 每年買在最低點 | ❌ 無法預知低點 |
| 📅 **DCA** | 每月固定金額投入 | ✅ 最實用、最易執行 |
| 😱 **地獄倒霉鬼** | 每年買在最高點 | ❌ 最差情況參考 |

- XIRR 年化報酬率計算（Newton-Raphson）
- 調整後收盤價（adjClose）— 含股息再投入、股票分割
- 視覺化走勢圖（Recharts）

### 🎵 樂活五線譜

對歷史收盤價做**對數線性迴歸**，畫出五條參考線：

| 線條 | 說明 |
|------|------|
| 🔴 樂觀線（+2σ） | 歷史上偏貴區域 |
| 🟠 相對樂觀（+1σ） | 稍微偏高 |
| ⚪ 趨勢線 | 長期均值迴歸中心 |
| 🔵 相對悲觀（-1σ） | 稍微偏低 |
| 🟣 悲觀線（-2σ） | 歷史上偏便宜區域 |

- R² 決定係數：判斷趨勢擬合度
- CV 變異係數：判斷標的穩定性
- 適合 ETF 或具均值回歸特性的標的（如 0050.TW、VOO）

### 🔍 歷史價格查詢

任意指定股票代號與日期區間，查詢每日 OHLCV + 調整後收盤價。

## 計算說明

### 策略投入邏輯

- **單筆投入**：總金額 = 月投 × 總月數，第一個交易日全部買入
- **DCA**：每月第一個交易日購買固定金額
- **天選之人**：每年最低價那天投入年度預算（月投 × 12）
- **地獄倒霉鬼**：每年最高價那天投入年度預算

### XIRR 年化報酬率

每次買入為負現金流，最終市值為正現金流，用 Newton-Raphson 求解年化報酬率，考慮每筆投入的實際時間複利效應。

### 樂活五線譜演算法

1. 取每月最後交易日收盤價（調整後）
2. 對 `ln(price)` 做 OLS 線性迴歸
3. 計算殘差標準差 σ（n-2 自由度）
4. 各線 = `exp(trend ± k * σ)`，k = 0, 1, 2
5. R² = 1 - SS_res / SS_tot
6. 圖表使用每日資料（最多採樣 500 點）

## 注意事項

- 回測**未計算**手續費、稅費、滑點
- 五線譜適合 ETF，個股效果可能有限（建議 R² > 0.85）
- 資料來源：Yahoo Finance（非即時，有 15 分鐘延遲）
- 過去績效不代表未來表現，不構成投資建議
